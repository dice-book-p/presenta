## 업로드 방법

### 방법 1: 마이그레이션 스크립트 (자동, WebP 변환 포함)

```bash
# .env 파일에 Supabase 환경변수 설정 필요
node --env-file=.env scripts/migrate.js
```

- JPG → WebP(quality 90) 자동 변환 후 Supabase slides 버킷에 업로드
- `projects.json`, `signatures.json` 자동 생성

### 방법 2: 어드민 UI (수동)

1. 서버 실행 후 `/admin` 접속
2. 새 프로젝트 생성
3. 슬라이드 탭에서 이미지 파일 업로드 (자동 WebP 변환)
4. 순서 드래그로 정렬
5. 서명자 탭에서 서명자 설정

## 주의사항

- `static/img/` 폴더의 원본 JPG와 동일한 파일입니다
- 실제 운영 배포 시 마이그레이션 스크립트를 1회 실행합니다
- 이 `docs/slides/` 폴더는 참조용이며 서버에서 직접 서빙하지 않습니다
